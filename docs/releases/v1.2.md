## 中文

欢迎使用 **豆间 Bean Journal v1.2**！

本次更新让查看豆卡、选择产地和记录冲煮时间更加便捷。

### 本次更新

- 🧭 **首页快捷跳转**：点击“我的豆子”“冲煮记录”“心选配方”统计，直接进入对应页面。
- 🫘 **整张豆卡可点击**：点击卡片即可查看详情，“冲一杯”按钮仍独立进入冲煮记录。
- 🔎 **国家搜索**：支持中文、英文搜索，直接点击匹配结果选择国家。
- 🌐 **产地语言修复**：切换语言后，豆卡上的国家名称立即更新，产区和庄园原文保持不变。
- 🔥 **新增中深烘**：支持中深烘选择、筛选和对应豆卡配色。
- ⏱️ **萃取计时器**：位于冲煮记录的萃取时间输入框右侧，停止后自动填入秒数，支持重新计时；配方仍保留手动填写的目标时间。

### Docker 更新

镜像：`tzbqweas/bean-journal:1.2`  
`latest` 同步指向 v1.2；支持 `linux/amd64`。

使用镜像版 Docker Compose 部署时，运行：

```sh
docker compose pull
docker compose up -d
```

如配置中固定使用旧标签，请先将其改为 `tzbqweas/bean-journal:1.2`。仓库自带的 Compose 使用本地构建，应运行 `docker compose up -d --build`。

### 更新提示

- 更新前建议在设置中导出备份，并保持原访问地址和端口。
- 数据仍保存在当前浏览器，本版本不包含账号或多端同步。
- 自动回归测试和容器健康检查已通过；手机、iPad 的完整真机验证仍待完成。

感谢你使用豆间！

## English

Welcome to **Bean Journal v1.2**!

This update makes it easier to browse your beans, select origins and record brewing time.

### What's New

- 🧭 **Dashboard shortcuts:** click the bean, brew or favorite-recipe totals to open the corresponding page.
- 🫘 **Clickable bean cards:** click anywhere on a card to open its details. The Brew button still starts a brew independently.
- 🔎 **Country search:** search in Chinese or English and select a country directly from the matching results.
- 🌐 **Origin language fix:** country names on cards update immediately when switching languages. Region and farm text stays unchanged.
- 🔥 **Medium-dark roast:** added to roast selection, filters and card colors.
- ⏱️ **Brew timer:** next to the extraction-time input in brew records. Stop it to fill in elapsed seconds, or restart for a new measurement. Recipes retain their manually entered target time.

### Docker Update

Image: `tzbqweas/bean-journal:1.2`  
`latest` also points to v1.2. Supported platform: `linux/amd64`.

For an image-based Docker Compose deployment:

```sh
docker compose pull
docker compose up -d
```

If your configuration pins an older tag, change it to `tzbqweas/bean-journal:1.2` first. The repository's bundled Compose file builds locally; use `docker compose up -d --build` instead.

### Before Updating

- Export a backup from Settings and keep the same access address and port.
- Data remains in the current browser. Accounts and cross-device sync are not included.
- Automated regression tests and container health checks passed. Full phone and iPad hardware testing remains pending.

Thank you for using Bean Journal!
